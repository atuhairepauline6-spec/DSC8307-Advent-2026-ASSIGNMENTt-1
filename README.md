# DSC8307 Assignment Submission Package
Files:
- project1_bank_marketing.ipynb — Project 1 executable notebook
- project2_concrete_strength.ipynb — Project 2 executable notebook
- consolidated_assignment_report.md — worked report and interpretation
- requirements.txt — Python dependencies
- bank-additional-full.csv / Concrete_Data.csv — supplied datasets
- *_README.txt — supplied data dictionaries

Run:
1. Extract this folder.
2. Install Python 3.10+.
3. Run `pip install -r requirements.txt`.
4. Start Jupyter with `jupyter lab` or `jupyter notebook`.
5. Open and run each notebook from top to bottom.

Important: Review and personalize the report, rerun the notebooks, verify results, and comply with university academic-integrity and referencing rules before submission. The notebooks use relative data paths and fixed random seeds.
